# Linear-size sparsifiers for sums of seminorms

- `paper.pdf` is the version linked from the Repository page.
- `paper.tex` and `references.bib` are the arXiv-ready source files.
- `paper.bbl` is included so the source can be compiled without running
  BibTeX on the first pass.

To rebuild:

```text
pdflatex paper.tex
bibtex paper
pdflatex paper.tex
pdflatex paper.tex
```
